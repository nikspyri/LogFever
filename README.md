# FeverLog

Android app for parents to log a child's fever, medication, symptoms and photos, and keep doctor contacts at hand.

- Fully offline: no server, no account, no network access
- English by default, multi-language by design
- Does not diagnose, does not suggest doses

**Status:** planning. No code yet.
