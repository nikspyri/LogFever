# UI mockups

Layout and tone reference for the Android app. Read `docs/ui-design-brief.md` §14 first: it lists which values in the mockups are samples and must not be copied into code.

`mockup-sources/` holds the HTML source of each screen (390 x 844 phone frame). The files were made in a design-canvas tool and need its runtime (`support.js`) to render, so they do not open correctly on their own. Use them to read exact sizes, colours, spacing and copy, not to run.

Screens: Main (Home with period-selectable chart), LogTemp, LogDose, AddMedicine, DoseWarning (placeholder), Timeline, Contacts, Onboarding, Settings, Symptoms, Siblings (two children), Night (night theme).

Colours used (sample palette, not final tokens): primary teal #1B645C, ink #12302C, muted #4F6662, ground #F3F6F5, card border #D5E0DD, fever tint #FBEBE4 / ink #8A3A22, action red #C0392B, night ground #17120F.
